## 기기마다 확인할 항목
| 항목 | 확인 내용 |
|---|---|
| ① 브라우저 버전 | 설정 → 정보에서 확인해 기록 |
| ② 화면 | 폭 360px에서 깨지지 않는지 (M4) |
| ③ 모델 로딩 시간 | 진단 진입 후 준비될 때까지 초 (첫 번째 / 두 번째) |
| ④ 사진 선택 | 앨범에서 사진을 고를 수 있는지 |
| ⑤ HEIC 사진 | iPhone 기본 형식 사진이 열리는지. PC Chrome·Edge는 못 열 수 있어 안내 필요 여부 확인 |
| ⑥ 세로 사진 방향 | 세로로 찍은 사진이 눕지 않는지 (EXIF 회전) |
| ⑦ 얼굴 검출 | 정면 1명 성공 / 2명 → `face_multiple` / 얼굴 없음 → `face_not_found` |
| ⑧ 처리 시간 | 사진 선택부터 결과까지 초 (목표 약 5초) |
| ⑨ 큰 사진 | 원본 고해상도 사진에서 멈추거나 튕기지 않는지 |
| ⑩ 외부 요청 0건 | 아래 방법. 휴대폰은 원격 디버깅이 가능한 경우만 |
| ⑪ 인앱 브라우저 | 파일 선택이 되는지, 안 되면 "외부 브라우저로 열기" 안내가 필요한지 |

## "외부 요청 0건" 확인 방법 (결정 로그 M3-D1)
1. 진단(개발용 화면) 페이지에서 개발자 도구(F12) → **Network** 탭
2. **Preserve log**, **Disable cache** 켜기
3. 필터 칸에 `-domain:<우리 사이트 주소>` 입력 (우리 사이트가 아닌 요청만 보임)
4. 사진을 넣고 진단을 끝까지 진행한 뒤 **70초 이상** 기다림 (MediaPipe 지표 전송은 60초마다 시도)
5. **통과:** 남은 요청 0건, 또는 남은 요청의 상태가 모두 `(blocked:csp)`
   - `odml.pa.googleapis.com` 차단 기록은 정상
   - Console의 CSP 경고도 캡처해 기록
6. 개발자 도구 없이: 개발용 화면의 **"보안 설정(CSP)이 차단한 요청 수"** 표시로도 확인 가능
