## M3-2 결과 요약 (07 "M3-2 범위와 완료 기준", 02)
- **톤 ID** = `{계열}_{명도}_{채도}` (예: 9번 `cool_light_vivid`). **M6부터 동결.** 12톤 ID는 `계절_이름`

- **조명 보정** (`packages/core/src/lighting.ts`): 보정 안 함 / 회색 세계 가정, **선형 색 공간**. 기준 통계는 색 편향과 같은 영역(얼굴·목 밖, web `measureLightingReference`). 기준 없음·영역 작음·배율 한도 초과 → 자르지 않고 "보정 안 함" + `lighting_fallback`(새 이유 코드, 경고). 한도 "사용 안 함"이면 큰 배율도 적용·경고 없음. 설정에서 "보정 안 함"을 고르면 경고 없음
- **판정** (`tone.ts`의 `judgeTone`): 경계와 같은 값은 "이상" 쪽. 2순위 = 척도로 나눈 거리가 가장 작은 축의 이웃 칸, 동점은 웜/쿨 > 명도 > 채도. **대비는 판정에 쓰지 않음**
- **신뢰도** (`confidence.ts`): 다섯 요소 가중 평균. ⑤ 영역 간 일관성 = 피부 영역끼리 최대 ΔE2000(`skinSpread`, 가림 사진을 잡는 도구). 대비·12톤 확신 낮음 제외, `lighting_fallback`은 품질 플래그 수로 반영
- **ColorProfile** (`profile.ts`의 `buildColorProfile`): 품질 실패면 만들지 않음, `createdAt`은 밖에서 받음, 좌표·측정값·중간값 미포함(O-2)
- **세부 규칙 4가지 [임시, 승인됨]:** 명도 두 경계 거리 같으면 어두운 쪽 / 회색 세계 배율 = 세 채널 평균 ÷ 채널 평균 / 신뢰도 요소별 점수식 / 피부 영역 1개면 일관성 0
- **비어 있는 설정 (M3-3에서 채움):** 16톤 경계값·2순위 척도(`TONE_THRESHOLDS`), 보정 방식·최소 영역·배율 한도(`LIGHTING_CONFIG`), 신뢰도 가중치·일관성 척도(`CONFIDENCE_CONFIG`), 품질 기준(`QUALITY_CONFIG`). 지금 판정하면 "미설정" 오류가 정상
- **개발용 화면 확인:** MediaPipe 공식 테스트 사진 1장으로 미리보기·두 보정 방식 특징값·판정 "미설정"·외부 요청 0건(CSP 차단 1건: 지표) 확인. 임시 폴더·사진 삭제. **실제 사람 사진 확인은 기획자가 본인 사진으로 다음 세션에 해 볼 것**

## 중요한 주의점
- **CSP 차단 유지.** 외부 서버(예: M6 Supabase)를 붙일 때만 `apps/web/src/lib/security/csp.ts`에 주소를 명시적으로 추가하고 결정 로그에 남긴다.
- **샘플 사진·실측 수치는 저장소 폴더 밖에서만.** 커밋 금지(`.gitignore`·`check:photos`가 사진을 막음). **성인임이 분명하지 않은 사진은 쓰지 않는다.**
- **fixture는 지어낸 숫자만.**
- 공개 사진을 받을 때는 서버가 알려준 대기 시간(Retry-After)을 지키고, 제한 우회·요청 쪼개기 금지.
- **push 규칙:** 문서만 바뀐 커밋은 바로 push, 코드 커밋은 마일스톤 완료 승인 후. **push 전 `git log origin/main..HEAD`로 올라갈 커밋 전체 확인** (2026-10-08 사고, 결정 로그 운영-push-사고).
- [미정]은 추정으로 채우지 않고 질문한다. 품질 기준·16톤 경계값·2순위 척도·조명 보정 설정·신뢰도 가중치는 비어 있으며, 비어 있는 채로 쓰면 "미설정" 오류가 나는 것이 정상이다.
- Windows + 한글 사용자 폴더에서 Node 24.10 `fs.rmSync(recursive)`가 비정상 종료한다. 스크립트·테스트에서 쓰지 않는다.
- 개발용 확인: `npm run dev` → `http://localhost:3000/dev/diagnosis/` (화면에 "CSP가 차단한 요청 수" 표시). 끝나면 3000번 포트가 비었는지 확인(하위 node 프로세스가 남을 수 있음).
- 자동 화면 확인이 필요하면 저장소 밖 임시 폴더에 `playwright-core`를 설치하고 이미 설치된 Chromium(`%LOCALAPPDATA%/ms-playwright/chromium-1234/chrome-win64/chrome.exe`)을 쓴다. `chrome --dump-dom`은 개발 서버에서 끝나지 않으므로 쓰지 않는다. 끝나면 임시 폴더·사진 삭제.
- **톤 ID는 M6부터 동결.** 이름을 바꿔도 ID는 바꾸지 않는다.
