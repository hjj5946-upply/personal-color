## 중요한 주의점
- **CSP 차단 유지.** 외부 서버(예: M6 Supabase)를 붙일 때만 `apps/web/src/lib/security/csp.ts`에 주소를 명시적으로 추가하고 결정 로그에 남긴다.
- **샘플 사진·실측 수치는 저장소 폴더 밖에서만.** 커밋 금지(`.gitignore`·`check:photos`가 사진을 막음). **성인임이 분명하지 않은 사진은 쓰지 않는다.**
- **fixture는 지어낸 숫자만.**
- 공개 사진을 받을 때는 서버가 알려준 대기 시간(Retry-After)을 지키고, 제한 우회·요청 쪼개기 금지.
- **push 규칙:** 문서만 바뀐 커밋은 바로 push, 코드 커밋은 마일스톤 완료 승인 후. **push 전 `git log origin/main..HEAD`로 올라갈 커밋 전체 확인** (2026-10-08 사고, 결정 로그 운영-push-사고).
- [미정]은 추정으로 채우지 않고 질문한다. 품질 기준·16톤 경계값·신뢰도 가중치는 비어 있으며, 비어 있는 채로 쓰면 "미설정" 오류가 나는 것이 정상이다.
- Windows + 한글 사용자 폴더에서 Node 24.10 `fs.rmSync(recursive)`가 비정상 종료한다. 스크립트·테스트에서 쓰지 않는다.
- 개발용 확인: `npm run dev` → `http://localhost:3000/dev/diagnosis/` (화면에 "CSP가 차단한 요청 수" 표시). 끝나면 3000번 포트가 비었는지 확인(하위 node 프로세스가 남을 수 있음).
