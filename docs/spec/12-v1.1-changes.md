# 12. v1.0 이후 추가·변경 (v1.1) — **승인됨 (2026-10-08, 결정 로그 M0-7)**

6개 항목 모두 기획자가 승인했다. 대화 프로젝트 지침서에도 반영한다.

1. **샘플 사진 커밋 금지:** 사진은 절대 커밋하지 않는다. 사진에서 뽑은 수치 fixture(JSON)만 커밋. (`.gitignore` + `npm run check:photos`)
2. **M3 직후 정확도 점검 관문:** 지인 샘플로 진단 결과의 타당성을 확인한 뒤에 M4로 진행한다.
3. **M7 후 중간 공개:** 진단 중심 중간 공개(최소 처리방침·약관 필요)를 고려한다.
4. **지침서 §0 문구 갱신:** "현재 단계: 구현 착수 전" → 구현 중으로 변경.
   > 주의: 여기서 **§0은 대화 프로젝트 지침서(v1.0 원문)의 절**이다. `docs/spec/`에는 §0이 없다. 저장소에서 같은 역할은 `CLAUDE.md`의 "현재 상태"가 맡는다.
5. **샘플링 예외 케이스 처리:** 안경, 앞머리, 수염, 염색 머리, 진한 화장.
6. **일정 재추정:** M0~M3 완료 후 다시 추정한다.
