## M3-1b 축소 상한 실측 (2026-10-19, 결정 로그 M3-1b-상한제안·M3-1b-사진제외)

**방법:** 개발용 화면(`/dev/diagnosis/`)을 설치된 Chrome(PC)으로 자동 실행. 사진 14장 × 상한 7개(원본·2048·1600·1280·1024·768·512) × CPU 감속 2종(1배 3회, 4배 2회). 원본 크기 결과를 기준으로 영역별 ΔE2000을 비교. **같은 조건 반복 실행 결과는 완전히 같음(결정적).** 진단 중 외부로 나간 요청 **0건**, CSP 차단 2건(페이지마다 MediaPipe 지표 1건). 모델 로딩 1배 0.9초 / 4배 1.9초. 사진·사진별 수치는 저장소 밖에서만 다루고 실측 후 삭제(D8). 아래는 집계만.

- **통과 조건(M3-1b-Q6·ΔE범위)을 13장 전체로 엄격히 적용하면 통과하는 상한이 없다.** 피부 ΔE 최댓값이 모든 상한에서 2.0을 넘는다. 원인은 **3장**에 몰려 있다: **옆얼굴**(무대 조명), **고개를 크게 돌린 얼굴**, **손·연기가 볼을 가린 사진**. 이 3장은 2048에서도 크게 흔들리고(상한이 커져도 줄지 않음), 피부 샘플 영역이 얼굴 경계·가림 물체에 걸치는 것이 원인으로 보인다(머리카락과 같은 종류의 문제).
- **3장을 뺀 근거와 한계 (결정 로그 M3-1b-상한확정):** 이 10장은 **결과를 본 뒤에 고른 것**이다. 3장을 뺀 근거는 "**상한을 키워도 차이가 줄지 않아 상한 문제가 아니라 피부 영역 문제**"라는 점이다. "그 3장이 품질 검사에서 걸러진다"는 것은 **확인되지 않은 가정**이므로 M3-3에서 각도·가림 기준이 실제로 걸러내는지 확인한다(안 걸러지면 피부 영역 수정, 위 [M3-3 숙제]).
- **위 3장과 얼굴을 못 찾은 1장을 뺀 10장**에서는 피부 ΔE 최댓값 2.0 이하를 만족하는 가장 작은 상한이 **1280**(중앙값 0.30, 최댓값 1.63)이다. 1024부터는 **1장(어두운 피부, 고개를 조금 돌린 얼굴)**에서 피부 ΔE가 커진다(최대 3.54). 얼굴이 더 작게 찍힌 다른 어두운 피부 사진은 512까지 1.1 이하로 안정적이어서 원인을 단정할 수 없다. 4배 감속 처리 시간은 2048 이하 모든 상한이 5초 이내.
- **얼굴 검출:** 1장(밝은 피부, 실내, 고개를 든 얼굴·모자·안경)은 원본~768에서는 얼굴을 못 찾고 512에서만 찾았다. 512에서는 다른 1장의 영역 수도 원본과 달라졌다 → 512는 "검출 결과 동일" 불통과. 검출 실패 시 더 작은 크기로 재시도하는 방안은 M3-2 후보(위 [M3-2 후보]).
- **결론: 긴 변 1280px을 PC 기준 잠정값으로 확정**(2026-10-19 기획자 승인). M3-3 샘플과 M4 실기기에서 재확인한다.
- **1280에서 측정값이 원본과 달라진 최대 폭(13장):** 얼굴 크기 11%, 얼굴 각도 2.0°, 밝기(어두운 쪽) 0.005, 밝기(밝은 쪽) 0.012, 색 편향 0.24, 선명도 76%(02 `sharpness` 한계 참고). 색 편향 "측정 가능/불가"가 바뀐 사진은 없음.
- **피부 톤·조명 다양성:** 밝은 피부 8장, 중간 피부 4장, 어두운 피부 2장. 조명은 야외 낮·스튜디오(흰·회색·단색 배경)·실내 따뜻한 빛·저조도 측광·무대 색 조명(붉은 빛 포함)·야외 따뜻한 빛. **형광등 조명 사진은 없다.** 어두운 피부 2장 중 1장은 모든 상한에서 안정적이었고, 1장은 1024 이하에서 ΔE가 커졌다(1280 이상은 통과). **어두운 피부가 2장뿐이라 피부 톤의 영향은 단정할 수 없다. 밝기 공정성(밝기 두 비율 포함)은 M3-3 샘플(13 "튜닝용 정답 샘플")에서 다시 확인한다.**
- **한계:** PC 한 대(Chrome)의 결과. 휴대폰은 M4에서 재확인(15-device-checklist). 사진 수가 적고 공개 사진이라 셀카와 구도가 다르다.

**사용한 사진 (14장, 출처·라이선스).** 번호·출처 사이트·라이선스 종류만 남긴다. 인물 이름이 든 주소는 저장소에 두지 않고 **저장소 밖 로컬 파일로만** 보관한다. 내려받은 원본 그대로 사용(수정·재배포 없음), 실측 후 삭제.
