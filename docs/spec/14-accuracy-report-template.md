## 3. 결과
정답이 해당 수준까지 있는 샘플만 그 수준에서 센다. 예를 들어 정답이 "웜"까지만 있으면 웜/쿨에서만 센다.

| 수준 | 대상 샘플 수 | 일치 수 | 일치율 | 기준 | 통과 |
|---|---|---|---|---|---|
| 웜/쿨 | | | | | ✅/❌ |
| 4계절 | | | | | ✅/❌ |
| 16톤 1순위 | | | | | ✅/❌ |
| 16톤 2순위 포함 | | | | | ✅/❌ |

### 3-1. 혼동표 (개수만)
- **웜/쿨 2×2:** 행 = 정답, 열 = 판정
- **4계절 4×4:** 행 = 정답, 열 = 판정
- **16톤:** 칸이 많아 한 칸에 1~2명이 되기 쉽다. 사람을 알아볼 수 있으므로 **"축별 오차"로 대신 보고한다.**
  - 웜/쿨 틀림 n, 명도 1단계 차이 n, 명도 2단계 이상 차이 n, 채도 틀림 n

## 4. 해석과 제안
- 기준 통과 여부 요약
- 가장 많이 틀린 축과 추정 원인 (조명, 화장, 염색 등. v1.1 5번 예외 케이스)
- 기준값 조정 제안과 `configVersion` 변경 이유
- **M4 진행 / 보류 제안** → 기획자 결정
