# 05. 데이터 설계(8) · 과금·쿼터·스위치(9)

## 테이블
| 테이블 | 용도 |
|---|---|
| `users`, `user_profiles` | 계정, 표시 이름, 기본 스타일 방향, `ageTier`와 확인 시각, 대표 진단 |
| `consents` | 동의 종류, 문구 버전, 동의·철회 시각 (**쌓기만 함**) |
| `color_profiles`, `diagnosis_feedback` | 진단 결과, 정답지 |
| `outfit_requests`, `outfits`, `outfit_feedback` | 코디 입력, 결과, 피드백 |
| `garment_matches`, `tryon_jobs` | 옷 색 매칭, 가상 피팅 메타데이터(**사진 없음**) |
| `usage_events` | 모든 기능 호출 기록 (비용 추정치 포함) |
| `credit_ledger`, `plans`, `subscriptions`, `payments` | 크레딧 장부, 상품, 구독, 결제 내역(카드 정보 저장 금지) |
| `feature_flags` | 기능 스위치 |
| `affiliate_clicks` | 제휴 클릭 로그 (3단계) |

- **모든 테이블에 RLS 필수** ("본인 행만 읽고 쓴다")
- **삭제 정책:** 탈퇴 시 개인에 연결된 모든 데이터(진단, 코디, 피드백 포함) 삭제. 법령상 보관 필요한 **결제 기록만 분리 보관**(3단계, 기간 [확인필요]). **튜닝 결과는 설정 파일(기준값)에만 남기고, 개인별 원본 정답 데이터셋은 만들지 않는다.** 튜닝용 실제 샘플(사진, 거기서 뽑은 수치, 정답 톤)은 **저장소 폴더 밖에서만** 쓰고 **튜닝 후 삭제**한다(참여자가 요청하면 즉시 삭제). 저장소에는 기준값과 **집계된 정확도**만 남긴다(결정 로그 M3-D8).
- **백업:** 월 1회 내보내기, **최근 N개만 유지**, 오래된 것은 폐기. 처리방침에 "백업에서는 최대 N일 후 삭제" 명시. (N은 [미정])

## 과금·쿼터
- **크레딧 원장**(쌓기만 함): 무료 지급, 구매, 구독 지급, 사용, 만료를 한 줄씩. 1단계는 **기록만 하고 차감하지 않는다.**
- 기능별 크레딧 비용은 설정값. 구독은 "매월 N크레딧 지급 권한". 미사용 구매 잔액 추적(환불 계산용).
- **`canUse(user, feature) → {allowed, remaining, reason}`** 한 곳에서만 판단. (UI와 서버 모두 호출)

| 기능 | 비용 | 비로그인 | 로그인 |
|---|---|---|---|
| 진단, 드레이핑, 옷 색 매칭 | 0원 | 허용 | 허용 |
| 개인화 코멘트, 코디 (Claude) | 소액 | 불가 | 일일 한도 |
| 가상 피팅 | 가장 큼 | 불가 | 일일 한도(작게), 만 19세 이상 |

- **전체 월 예산 차단기(`COST_GUARD`)는 항상 ON.** 월 변동비 상한은 "소액", **설정값(숫자 [미정], 초기값은 가장 낮게)**. 도달하면 해당 기능 자동 잠금 + 안내. 각 업체 콘솔에도 자체 한도 설정.

| 스위치 | 기본값 |
|---|---|
| `QUOTA_ENFORCED`, `PAYMENT_ENABLED`, `ADS_ENABLED`, `AFFILIATE_ENABLED` | OFF |
| `TRYON_ENABLED` | OFF (2-2단계에서 ON) |
| `COST_GUARD_ENABLED` | **항상 ON** |
| `KILL_SWITCH_*` | OFF (기능별 긴급 차단) |

- 스위치는 DB(런타임). 결제 SDK처럼 번들에 포함되는 항목만 빌드 시 환경변수.
- 결제는 `PaymentProvider`(웹 PG / 앱 스토어)로 추상화, **결과는 항상 장부에 "+크레딧" 한 줄**. **결제 검증은 서버에서**, 카드 입력은 PG·스토어 화면.
- 광고는 `<AdSlot>` 자리만 예약, 제휴는 `searchQuery`→쇼핑 링크 인터페이스만 정의(3단계). 제휴 링크에는 **"제휴 링크 / 수수료를 받을 수 있어요"** 라벨 기본 부착.
- 앱 스토어·PG 수수료·정책은 3단계 착수 시 재확인 (구글 한국 2026년 12월 수수료 개편 보도, 애플 외부결제 26% 설명 등 — 모두 [확인필요]).
