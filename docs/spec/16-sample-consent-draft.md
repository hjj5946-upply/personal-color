# 16. 정확도 점검 샘플 참여 동의서 (초안)

> 결정 로그 M3-D7. **일반적인 초안이며 법률 자문이 아니다.** 얼굴 사진은 개인정보이므로 수집 전에 기획자가 다듬는다.
> 샘플 보관 규칙은 결정 로그 M3-D8(저장소 폴더 밖에서만, 튜닝 후 삭제, 커밋은 기준값·집계 정확도만).

---

**[퍼스널컬러 진단 정확도 점검 참여 동의서]**

**1. 목적**
개발 중인 퍼스널컬러 진단 기능이 얼마나 정확한지 점검하는 데**만** 써요. 다른 목적(서비스 홍보, 학습용 데이터 판매, 얼굴 인식 등)에는 쓰지 않아요.

**2. 받는 정보**
- 얼굴 사진 (1~3장)
- 사진에서 계산한 색 수치 (피부·머리카락·눈동자 색)
- 알려주신 퍼스널컬러 진단 결과 (예: 여름 쿨 라이트, 받은 곳의 종류)

이름은 받지 않고, 사진은 번호로만 구분해요.

**3. 보관 장소와 방법**
운영자 개인 컴퓨터 안의 별도 폴더에만 보관해요. **코드 저장소(GitHub), 서버, 클라우드에 올리지 않고** 다른 사람에게 보내지 않아요.

**4. 보관 기간**
정확도 점검이 끝나면 **바로 삭제**해요. (예정: ____년 __월)

**5. 결과 공개 범위**
점검 결과는 "웜/쿨 일치율 OO%"처럼 **여러 사람을 합친 숫자로만** 남겨요. 누구의 결과인지 알 수 있는 형태로는 남기지 않아요.

**6. 동의 기록과 샘플의 분리**
**이 동의서(동의 확인 기록)와 샘플 번호는 서로 연결하지 않아요.** 동의 기록만 보고는 어떤 사진이 누구 것인지 알 수 없게 따로 보관해요.

**7. 삭제 요청**
언제든 ____(연락처)로 말씀해 주시면 **즉시 삭제**하고 삭제했다고 알려 드려요. 참여를 거부하거나 중간에 그만두셔도 불이익은 없어요.

**8. 참여 조건**
**만 19세 이상**만 참여할 수 있어요.
