# 04. 비기능 요구사항 (7)

## 지원 환경 [기본값]
- 브라우저: 모바일 Safari(iOS), Chrome(Android), Samsung Internet, 데스크톱 Chrome·Safari·Edge. 각각 **최신 2개 메이저 버전**. 구형 브라우저·IE 미지원
- 최소 화면 폭 360px. 모바일 우선, PC는 중앙 컬럼
- 카메라는 HTTPS 필요. 카메라 권한 거부·미지원 시 **앨범 업로드로 안내**(폴백)
- **인앱 브라우저(카카오톡 등):** 카메라, 파일 선택, 다운로드가 제한될 수 있다 [확인필요: 실기기 테스트]. 감지하면 "Chrome/Safari 같은 외부 브라우저로 열어주세요" 안내 배너

## 성능 목표 [기본값, 실측 후 조정]
- 사진 선택부터 결과까지: 중급 스마트폰 기준 **약 5초 이내**, 10초 넘으면 지연 안내
- 얼굴 모델 파일은 **진단 진입 시 지연 로딩**, 첫 로딩은 진행 표시. 홈 화면은 모델을 로드하지 않는다. 모델 크기 [확인필요]
- 입력 이미지는 분석 전에 상한 크기로 축소 (상한 수치 [미정])
- 코디 생성: 대부분 10초 이내, 초과 시 재시도 버튼

## 접근성 (WCAG 2.1 AA 목표)
- 텍스트 대비: 일반 4.5:1 이상, 큰 글자 3:1 이상 / 터치 영역 44×44px 이상
- **색만으로 정보를 전달하지 않는다.** 색 이름과 라벨 병기
- 이미지·아이콘 버튼에 대체 텍스트와 라벨, 포커스 표시, 키보드 조작
- 시스템 글자 확대 시 레이아웃 유지, 동작 줄이기 설정 존중
- **앨범 업로드가 항상 대체 경로**

## 색 정확도 구현 규칙
- 색 계산 전에 이미지를 **sRGB로 정규화**하고 **EXIF 회전**을 처리한다. 기기별 검증 필요 [확인필요]
- 판정 로직은 **결정적**. 같은 입력이면 같은 결과, 난수 금지. 테스트로 보장
- 분석이 끝나거나 취소되면 사진 객체, 임시 URL, 캔버스를 **즉시 해제**

## 기타 구현 규칙
- 언어는 한국어만(1단계). 모든 문구는 문구 파일로 분리(다국어 확장 대비). 시간대 Asia/Seoul
- 1단계 사이트는 **noindex**
- **외부 분석 도구(GA 등) 1단계 미사용.** 사용 통계는 자체 `usage_events`만. 도입 시 동의·처리방침 갱신
- 실패 폴백: 얼굴 모델 로딩 실패, 카메라 거부, 저장 실패 시 "이유 + 재시도 또는 대안 경로" 안내
