# 03. AI 코디 · 옷 색 매칭 · 가상 피팅 · 계정

## AI 코디 (6-2, 로그인 필수)
- **입력 4가지:** 내 톤(대표 진단 자동 입력, 없으면 직접 선택 또는 진단으로 이동) / 성별·스타일 방향(여성복, 남성복, 중성) / 상황 / 계절·날씨
- **출력:** 코디 **3벌**. 각 벌에 이름, 콘셉트, 아이템(상의·하의·아우터·신발·액세서리)별 색, 이유, 색칩 보드, 단순 실루엣 색칠 시각화
- **생성 구조:** 우리 팔레트 목록을 프롬프트에 넣고 "이 목록에서만 선택"하도록 지시 → 구조화(JSON) 출력 → **core에서 검증**(팔레트 밖 색이 있으면 폐기하고 재시도) → 화면
- 아이템 필드에 **`searchQuery`**를 포함한다. (1단계는 미사용, 제휴·피팅 연결 대비)
- **안전 규칙:** 외모·체형 평가 금지 / 성별 고정관념 없이 선택된 방향만 반영 / 상황에 맞는 격식 / 확인되지 않은 브랜드·가격 언급 금지 / 한국 계절·기온 기준
- **프롬프트에 식별 정보 금지** (톤, 스타일, 상황, 계절만)
- **비용 보호:** 서버에서만 호출 / 사용자별 일일 한도 / 같은 조건 캐시(단 "다시 추천"은 새 결과) / 모든 호출을 `usage_events`에 기록
- 코디 결과를 내보낼 때 "AI 추천" 문구를 포함한다.
- **피드백:** 벌별 👍👎, 사유(색 / 상황 / 취향)

## 옷 색 매칭 (6-3, 2-1단계, 비로그인 허용)
옷 사진 업로드 → 브라우저에서 대표 색 추출 → 내 팔레트와의 일치 점수 표시. 사진은 서버로 보내지 않고 저장하지 않는다.

## 가상 피팅 (6-4, 2-2단계, 만 19세 이상, 로그인 필수)
- 구조: `TryOnProvider` 인터페이스 / 서버 계층 경유 / 업체에는 **base64로 전달**하고 결과는 브라우저로 바로 반환 / **우리 서버 저장 없음**
- **최초 1회 별도 동의**(전송 대상, 목적, 보관 여부)와 철회 기능
- **색 검증:** 결과에서 옷 영역 색을 뽑아 원본 옷 색과 비교하고, 차이가 크면 "색이 다르게 나왔을 수 있어요" 경고
- **저장·공유 시 "AI 생성" 가시적 워터마크를 자동 삽입** (끌 수 없음)
- 업체 선정 기준(가중치 순): ① 옷 색 정확도 ② 얼굴·체형 보존 ③ 무늬·로고 ④ 실패율·속도 ⑤ 비용·해상도 ⑥ 데이터 보관 정책
- 후보: FASHN, Muapi, Pixelcut, ModelsLab 등. **확정 업체 없음.** 같은 사진·옷으로 직접 비교 테스트 후 선정
- 가격 참고(구현 전 재확인): FASHN 생성당 약 $0.075. 고품질 엔드포인트 가격과 해상도는 [확인필요]
- 오픈소스 직접 운영 제외 (비상업 라이선스 모델 다수, GPU 비용)
- 허용 카테고리: 의류(상의·하의·원피스). 얼굴 1명 검사, 업체의 보수적 검열 옵션 사용
- 업체 데이터 보관 정책은 도입 전에 약관·문의로 확정한다 [확인필요]

## 계정과 마이페이지 (6-5)
- 로그인: 카카오, 구글, 네이버(+애플은 앱). 수집은 최소화(이메일 없이도 가입 가능하게)
- 가입 체크: "만 14세 이상"(필수), "만 19세 이상"(선택). 저장은 `ageTier`(14+/19+)만 한다.
- 마이: 진단·코디 이력, 대표 진단 지정, 동의 관리·철회, 탈퇴(즉시 삭제)
